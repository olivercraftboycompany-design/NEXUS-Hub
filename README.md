# NEXUS Hub

One dashboard for all of Oliver's NEXUS apps: Bibley, nortest, NEXUS Calendar, NEXUS News, Ultimate Weather and Apologetics101.

Live: https://olivercraftboycompany-design.github.io/NEXUS-Hub/

All the apps share one site (olivercraftboycompany-design.github.io), so the Hub reads their saved data on the same phone/browser. It is read-only: it never writes, migrates or deletes another app's data. Its own keys start with `nxhub_`.
